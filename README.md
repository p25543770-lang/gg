# Камера с фиолетовыми углами

Приложение показывает изображение с камеры Logitech C930e и закрашивает четыре угла фиолетовым. Размер углов можно менять ползунком. Также работают другие камеры, поддерживаемые OpenCV.

## Готовая версия для Windows (без Python)

1. Откройте [GitHub Releases](../../releases) и скачайте `PurpleCorners.exe` из релиза этой программы, если он опубликован. Другие релизы репозитория могут относиться к другим приложениям.
2. Либо откройте [Actions → Windows camera app](../../actions/workflows/windows.yml), выберите успешный запуск для нужной ветки и скачайте артефакт **PurpleCorners-Windows-x64**. Для скачивания артефактов нужен вход в GitHub; артефакты хранятся 90 дней. Распакуйте ZIP.
3. Подключите камеру, закройте другие программы, использующие её, и дважды щёлкните `PurpleCorners.exe`. Python устанавливать не нужно. При первом запуске распаковка может занять некоторое время.
4. Нажмите «Открыть камеру». Если открылась не C930e или камера не найдена, попробуйте номера 1, 2 и т. д. Номер зависит от порядка устройств в системе. При необходимости разрешите доступ к камере в настройках конфиденциальности Windows.

Сборка предназначена для 64-битной Windows. В Actions проверяются запуск упакованного приложения, интерфейс и обработка тестового кадра без реальной камеры; работу с конкретной камерой нужно проверить на своём компьютере. Не подписанный цифровой подписью файл может вызвать предупреждение Windows SmartScreen.

## Сборка на Windows

Установите 64-битный Python 3.12 и выполните в папке проекта:

```bat
py -3.12 -m pip install -r requirements.txt pyinstaller==6.11.1
py -3.12 -m PyInstaller --noconfirm --clean --onefile --windowed --name PurpleCorners app.py
```

Результат — `dist\PurpleCorners.exe`. Python нужен только для сборки, а не для запуска готового файла. Workflow собирает его на Windows при push и pull request, а также запускается вручную через Actions.

## Запуск из исходного кода

В Windows установите Python 3.10–3.13 с [python.org](https://www.python.org/downloads/), отметив **Add Python to PATH**, затем выполните:

```bat
py -m pip install -r requirements.txt
py app.py
```

На Linux можно запустить `python3 -m pip install -r requirements.txt`, затем `python3 app.py`; может понадобиться системный пакет `python3-tk` и разрешение на доступ к видеоустройству.

Эффект отображается только в окне приложения: программа не изменяет настройки камеры и пока не создаёт виртуальную камеру для других приложений.
