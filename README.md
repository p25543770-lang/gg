# Камера с фиолетовыми контурами

Приложение показывает рядом изображения с двух камер (например, Logitech C930e) и выделяет фиолетовым контрастные контуры объектов и поверхностей, в том числе видимые границы дороги. Ползунок «Чувствительность контуров» регулирует количество выделяемых деталей: сдвиг вправо помогает увидеть менее контрастные границы, но добавляет шум. Также работают другие камеры, поддерживаемые OpenCV.

Это детектор перепадов яркости, а не распознавание дороги: он выделяет и другие объекты, может пропустить слабоконтрастные границы и зависит от освещения. **Не используйте его как единственный источник данных для управления роботом или обеспечения безопасности.**

## Готовая версия для Windows (без Python)

1. Откройте [GitHub Releases](../../releases) и скачайте `PurpleCorners.exe` из релиза `purple-corners-v1.6.0` или более нового релиза этой программы. Другие релизы репозитория могут относиться к другим приложениям.
2. Либо откройте [Actions → Windows camera app](../../actions/workflows/windows.yml), выберите успешный запуск для нужной ветки и скачайте артефакт **PurpleCorners-Windows-x64**. Для скачивания артефактов нужен вход в GitHub; артефакты хранятся 90 дней. Распакуйте ZIP.
3. Подключите одну или две камеры, закройте другие программы, использующие их, и дважды щёлкните `PurpleCorners.exe`. Python устанавливать не нужно. При первом запуске распаковка может занять некоторое время.
4. В левой и правой панели выберите разные номера камер (по умолчанию 0 и 1) и выберите разрешение в каждой панели, затем нажмите «Открыть». Чтобы изменить разрешение работающей камеры, нажмите «Закрыть», выберите новое значение и откройте камеру снова. Для работы только с одной камерой вторую панель можно не открывать. Кнопка «Закрыть» отключает соответствующую камеру. Если нужная камера не найдена, попробуйте другие номера: они зависят от порядка устройств в системе. При необходимости разрешите доступ к камере в настройках конфиденциальности Windows. Ползунок чувствительности общий для обеих панелей.

Под каждой камерой отображаются её FPS и два средних времени за последние 30 показанных кадров:

- **В приложении** — от получения кадра из OpenCV до передачи обработанного изображения виджету, включая ожидание в приложении.
- **Чтение** — сколько длился вызов OpenCV для получения кадра. Это часто время ожидания следующего кадра, а не его возраст или полная задержка.

Программа запрашивает выбранное разрешение (по умолчанию 640×480), MJPEG и 30 FPS, считывает камеры независимо и обрабатывает свежие кадры без искусственного ожидания между ними. Доступны 320×240, 640×480, 1280×720 и 1920×1080. Драйвер может не принять выбранное разрешение: фактический размер полученного кадра отображается под панелью вместе с предупреждением, если он отличается. Более высокое разрешение может снизить FPS. Драйвер может также не принять остальные параметры; реальная скорость зависит также от освещения, устройства и пропускной способности USB. Попробуйте подключить камеры к разным USB-контроллерам и улучшить освещение.

В Windows по умолчанию включена опция **«Экспозиция 1/32 с»**: при открытии программа пытается отключить автоэкспозицию и установить короткую выдержку, чтобы камера не снижала FPS при слабом свете. Изображение может стать темнее. Чтобы не менять экспозицию, снимите галочку **до открытия** камеры; для изменения во время работы закройте и откройте камеру. Если драйвер не поддерживает настройку, появится предупреждение. Программа пытается вернуть прежнюю экспозицию при закрытии, но это зависит от драйвера и не гарантируется при аварийном завершении.

Ни один из показателей не измеряет **полную задержку от съёмки до экрана**: задержки внутри камеры и драйвера до получения кадра и физический вывод на дисплей недоступны приложению.

Сборка предназначена для 64-битной Windows. В Actions проверяются запуск упакованного приложения, интерфейс двух панелей и обработка тестовых кадров без реальной камеры; работу с конкретной камерой нужно проверить на своём компьютере. Не подписанный цифровой подписью файл может вызвать предупреждение Windows SmartScreen.

## Сборка на Windows

Установите 64-битный Python 3.12 и выполните в папке проекта:

```bat
py -3.12 -m pip install -r requirements-windows.txt
py -3.12 -m PyInstaller --noconfirm --clean --onefile --windowed --name PurpleCorners app.py
```

Результат — `dist\PurpleCorners.exe`. Python нужен только для сборки, а не для запуска готового файла. Workflow собирает его на Windows при push и pull request, а также запускается вручную через Actions. Для публикации предварительного релиза запустите workflow вручную на нужной ветке и укажите новый тег вида `purple-corners-v1.0.0`; файл добавится в GitHub Releases после успешной проверки. Также релиз публикуется при push с заголовком коммита `release: purple-corners-v1.0.0` (используйте новый тег).

## Запуск из исходного кода

В Windows установите Python 3.10–3.13 с [python.org](https://www.python.org/downloads/), отметив **Add Python to PATH**, затем выполните:

```bat
py -m pip install -r requirements.txt
py app.py
```

На Linux можно запустить `python3 -m pip install -r requirements.txt`, затем `python3 app.py`; может понадобиться системный пакет `python3-tk` и разрешение на доступ к видеоустройству.

Эффект отображается только в окне приложения; виртуальная камера для других приложений не создаётся. Программа запрашивает параметры видеопотока и может временно изменить экспозицию, как описано выше.
